Webnovel Archiver: UI prototypes

Seven versions of the same app, built from your real library. v0 is today’s app, and each later version is more of a departure. Every version has the same features, so compare the design, not what each one can do.

How to compare: inside any prototype, tap the small vN tab on the left edge (drag it up or down if it’s in the way). It opens the version switcher, which keeps you on the same screen in the other version, and the feedback form. Notes save on the computer, tagged with the version and screen. Everything is simulated: playback, downloads, audio generation and AI generation animate, and nothing touches your real app.
